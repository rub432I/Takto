# Matt Pocock's Interactive "Teach" Skill

Transforms passive reading into an active, high-retention learning journey.

## Operational Flow

```
Complex Report / Codebase ──▶ [1. Domain Alignment & Glossary]
                                           │
                              [2. Core Mental Model & Diagram]
                                           │
                              [3. Bite-Sized Checkpoint Lessons]
                                           │
                              [4. Retrieval Quiz & Verification]
                                           │
                              [5. Feynman "Explain It Back" Check]
```

### Steps
1. **Domain Alignment:** Define technical terms before introducing mechanics.
2. **Visual Mental Model:** Generate a visual schema (Mermaid diagram) illustrating data flow.
3. **Bite-Sized Delivery:** Present concepts in short sections (under 300 words).
4. **Interactive Retrieval:** Stop after each section and quiz the user.
5. **The Feynman Finish:** Ask the user to explain the topic back in two sentences.
