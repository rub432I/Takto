# Optimized Learning Framework & 30-Day Study System

This skill implements Eero Alvar's 1-on-1 AI-assisted learning model and the 30-Day habit progression system.

## 1. The Probe-Plan-Teach Loop

```
[1. PROBE] ──▶ Binary search quiz questions to locate precise knowledge boundary
     │
[2. PLAN]  ──▶ Break topic into bite-sized steps with Mermaid visual diagrams
     │
[3. TEACH] ──▶ Deliver micro-lessons followed immediately by retrieval checks
```

- **Probe:** Never assume the student's background. Ask broad diagnostic questions, then narrow in using binary search to identify exact gaps.
- **Plan:** Use visual Mermaid diagrams, concept maps, and concrete analogies.
- **Teach:** Keep explanations under 3 paragraphs before posing an interactive retrieval question. Ensure the student actively struggles with the concept rather than passively reading.

## 2. The 30-Day Study Habit System

An incremental habit-stacking framework adding one new discipline per week:

| Week | Core Habit Added | Actionable Protocol |
| :--- | :--- | :--- |
| **Week 1** | Dedicated Focus Session | Study 45 min at a desk (phone in another room). Write daily study goal on physical paper before starting. |
| **Week 2** | Spaced Review & Prioritization | 10-minute review of yesterday's material at start of session. Set 3 weekly priorities every Sunday night. |
| **Week 3** | Explain-It-Back (Feynman) | End each block with a 2-minute closed-book verbal explanation as if teaching a peer. |
| **Week 4** | Active Retrieval Practice | Complete 3 practice question sets per week to force memory retrieval. |
