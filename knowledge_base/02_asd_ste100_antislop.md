# 02: ASD-STE100 & Eliminating AI Slop

**Source:** `youtube_pl.txt` (Lines 32-58)  
**Standard:** ASD-STE100 (Simplified Technical English, est. 1986)  

---

## Overview
"AI slop" is essentially **ambiguity with good posture**. Instead of banning individual words (a whack-a-mole approach), ASD-STE100 provides a mechanical, controlled language system that forces the model to prioritize clarity over flowery, hollow phrasing.

---

## Core Features of ASD-STE100
1. **Restricted Vocabulary (5:03 - 5:12):** Uses an approved dictionary of ~900 words where each word has exactly one meaning and one grammatical role.
2. **Grammar Constraints (1:46, 6:10):** 53 specific rules enforcing simple sentence structures, active voice, and banning complex verb constructions.
3. **Hard Length Caps (6:35 - 6:40):** Maximum **20 words** for instructional sentences, maximum **25 words** for descriptive sentences. Semicolons are prohibited.

---

## The Six Habits of AI Slop & How STE Eliminates Them

```
┌─────────────────────────┬───────────────────────────┬───────────────────────────────────┐
│ Slop Habit              │ STE Rule                  │ Mechanical Fix                    │
├─────────────────────────┼───────────────────────────┼───────────────────────────────────┤
│ 1. Synonym Rotation     │ Rule 1.11                 │ Exactly 1 approved word per item  │
│ 2. Hedging              │ Rule 3.4                  │ Ban filler/tentative verbs        │
│ 3. Frozen Verbs         │ Rule 3.7                  │ Use verbs, not nominalized nouns  │
│ 4. Marketing Adjectives │ Dictionary constraint     │ Ban "seamless", "robust", etc.    │
│ 5. Run-on Sentences     │ Rules 5.1 & 6.3           │ 20/25 word cap, ban semicolons    │
│ 6. Phrasal Verbs        │ Rule 9.3                  │ Use direct verbs (remove, not off)│
└─────────────────────────┴───────────────────────────┴───────────────────────────────────┘
```

1. **Synonym Rotation (Rule 1.11):** Alternating names for the same entity confuses the reader. Use a single terminology standard.
2. **Hedging (Rule 3.4):** Avoid phrases like *"It could potentially be argued that..."*. State facts directly.
3. **Frozen Verbs (Rule 3.7):** Instead of *"perform an analysis"*, write *"analyze"*. Instead of *"carry out an inspection"*, write *"inspect"*.
4. **Marketing Adjectives:** Ban hyperbolic buzzwords: *cutting-edge, robust, seamless, revolutionary, state-of-the-art*.
5. **Run-on Sentences (Rules 5.1 & 6.3):** Keep sentences short, active, and punchy.
6. **Phrasal Verbs (Rule 9.3):** Avoid informal multi-word verbs like *"take down"* (use *"record"*), *"look over"* (use *"examine"*).

> [!NOTE]
> STE governs the **form** of technical writing (removing ambiguity), but not the substance. Use it for documentation, code comments, pull requests, and system manuals.
