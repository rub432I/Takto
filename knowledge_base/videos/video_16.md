## 📝 Transcript Content & Summary

In the video, Griffin Wooldridge categorizes recommended UI libraries into three distinct types to help avoid the generic "AI look" when building with tools like Claude Code (0:00 - 0:27).

1. Foundations (0:30 - 1:24)

These libraries provide the core behaviors for components like buttons, inputs, and dialogs. You should use these for the base of your app and customize the radius, colors, and type to match your brand.

shadcn/ui
Base UI
Radix

2. Specialists (1:25 - 2:26)

These libraries are designed to excel at specific individual components that are notoriously difficult for AI to build correctly from scratch.

Sonner (Toasts)
Vaul (Drawers)
cmdk (Command menus)
NumberFlow (Number animations)

3. Design Components (2:27 - 3:39)

These are pre-styled, ready-to-use components perfect for specific needs like AI-specific interfaces or flashy marketing moments.

Beautiful UI (Best for AI interfaces like streaming text or agent approval cards)
RareUI (Animated buttons and text effects)
Magic UI (Animated components built on top of shadcn)
Aceternity UI (Landing page effects and 3D elements)
21st.dev (A marketplace for components from various design engineers)

Pro-Tip: Griffin recommends following the "One-Standout Rule"—keep only one major animated hero or interactive background per page to avoid a cluttered "AI-generated" look (3:40 - 3:55).
