## 📝 Transcript Content & Summary

To stop your UI from looking like a generic AI-generated template, Griffin Wooldridge recommends stop letting the AI build every component from scratch. Instead, you should provide it with specialized component libraries that ensure your product has character and proper functionality (0:00-0:27).

Here are the three categories of libraries to use:

Foundations: Use libraries like shadcn/ui, Base UI, or Radix to handle behavior (like accessibility and keyboard navigation), but customize the radius, colors, and type to match your brand (0:30-1:24).
Specialists: Use libraries that excel at specific, complex components that AI often fails to build correctly, such as Sonner for toasts, Vaul for drawers, cmdk for command menus, and NumberFlow for number animations (1:25-2:26).
Design Components: Incorporate finished, pre-styled components from libraries like Beautiful UI (great for AI-specific interfaces), RareUI, Magic UI, Aceternity UI, or 21st.dev for specific flashy moments (2:27-3:39).

Key Advice: Follow the One-Standout Rule—keep only one major animated hero or interactive element per page. Using too many will make everything glow and move, resulting in that recognizable, cluttered "AI-generated" look (3:40-3:55). To get Claude to use these libraries, explicitly name them in your prompt or install the pick-ui-library skill (3:56-4:17).
