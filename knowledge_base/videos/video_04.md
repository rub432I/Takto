## 📝 Transcript Content & Summary

A system prompt is a foundational set of instructions given to an AI model before it starts interacting with a user. Think of it as the AI's "rulebook" or "operating manual" that defines its personality, tone, boundaries, and how it should approach tasks.

Key functions of a system prompt include:

Defining Identity: It tells the AI who it is (e.g., a helpful assistant, a coding expert, or a creative writer).
Setting Constraints: It establishes rules for what the model should or should not do, ensuring safety and consistency.
Guiding Behavior: It provides the model with logic and reasoning patterns, such as how to format outputs or use specific tools.
Establishing Context: It frames how the model should interpret user requests, ensuring that its responses remain aligned with its intended purpose.
