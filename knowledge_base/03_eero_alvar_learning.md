**Source:** `youtube_pl.txt` (Lines 59-67)

## Overview
Shifts education from a traditional one-to-many model (lecture halls) to a high-efficiency one-to-one interaction (AI tutor). The core goal is to concentrate human mental effort on the **material itself** rather than logistics like planning or finding resources.

---

## The 3-Step Learning Architecture

```
         ┌──────────────────────────────────────────────────┐
         │ 1. PROBE (5:13)                                  │
         │ - Diagnostic quiz tool                           │
         │ - Binary search across knowledge boundaries      │
         └────────────────────────┬─────────────────────────┘
                                  ▼
         ┌──────────────────────────────────────────────────┐
         │ 2. PLAN (6:07)                                   │
         │ - Tailored curriculum for specific gaps          │
         │ - Sub-agents for fact-checking                   │
         │ - Visual aids (Mermaid diagrams, concept maps)   │
         └────────────────────────┬─────────────────────────┘
                                  ▼
         ┌──────────────────────────────────────────────────┐
         │ 3. TEACH (6:55)                                  │
         │ - Small, digestible micro-lessons                │
         │ - Frequent checks for understanding              │
         │ - Maximize cognitive struggle on material        │
         └──────────────────────────────────────────────────┘
```

### 1. Probe (5:13)
The AI identifies current understanding using an automated quiz tool. It starts with broad foundational questions and executes a binary search to map what the user understands vs. where their misconceptions lie.

### 2. Plan (6:07)
The system plans a custom curriculum for the identified gaps, deploying sub-agents to verify facts and generate Mermaid diagrams for visual learners.

### 3. Teach (6:55)
Delivers bite-sized lessons followed immediately by retrieval questions. This prevents the user from "gaslighting" themselves into believing they understand when they only recognize the text.
