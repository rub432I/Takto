# 07: Modern Web & UI Design Pipeline (Framer & Motion)

**Source:** `youtube_pl.txt` (Lines 106-146)  

---

## Overview
A 4-phase creative pipeline that combines AI generation with manual human polish to build high-end web experiences that don't look generic.

---

## The 4-Phase Design Pipeline

```
1. Visual Curation ──▶ 2. Asset Preparation ──▶ 3. Motion & Video ──▶ 4. Framer Assembly
   (Pinterest,            (Figma 16:9,              (Higgsfield               (Components &
    Midjourney)            Object Cleanup)           Miniax H3)                Human Polish)
```

### Phase 1: Visual Inspiration & Art Direction (1:05 - 1:47)
- Use **Pinterest** to explore aesthetic directions and layout moodboards.
- Use **Midjourney** to remix visual concepts and generate raw background artwork.

### Phase 2: Asset Preparation & Refinement (1:48 - 2:47)
- Use **Figma AI** to crop and expand background images into clean **16:9** aspect ratio suitable for responsive web heroes.
- Clean up artifacts and remove distracting elements.

### Phase 3: Motion Design & Video Generation (2:48 - 3:12)
- Convert static artwork into subtle animated backgrounds using **Higgsfield** with the **Miniax H3** model.
- Keep the camera motion stable and subtle so it enhances readability rather than distracting from typography.

### Phase 4: Assembly in Framer (3:13 - 5:30)
- **Base Hero:** Start with a clean canvas and use Framer AI agents to create the base container.
- **Video Embed:** Upload the animated background into the video component and adjust contrast overlay.
- **Component Recreation:** Recreate custom UI elements (like chat composers) by referencing screenshots.
- **The Human Touch (Mandatory Handoff, 4:48):** Manually fine-tune interactive states: hover effects, box shadows, focus outlines, and mobile viewport responsiveness.
